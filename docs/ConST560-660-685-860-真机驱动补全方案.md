## 八、风险点

1. **TAU.dll 为 4.x .NET Framework DLL**：与其他 Xmas11 DLL 一样在 net8 下可加载，但 TAUBase 用 `protobuf-net` 序列化，需确认 `protobuf-net.dll` 版本兼容
2. **ConST660 接口与仿真驱动方法不对齐**：仿真驱动有 30+ 专属方法不在接口中，需决策哪些纳入接口、哪些通过通用路由
3. **ConST860 需同时实现两套扩展接口**：`IConST860PressureQBase`（气压）和 `IConST860PressureYGbk`（液压），DPC2Base 能力需逐一确认
4. **ConST660/685/860 旧平台源码量大**（共 460KB）：移植工作量需分批进行
